# Прах и Железо

Браузерный арена-рогалик-автошутер: 20 волн на замкнутой арене, соло или в комнате
до 8 игроков. Оружие бьёт само — игрок бегает, уклоняется и принимает решения в лавке
между волнами. За забеги начисляются реликвии, за них открываются фракции, персонажи,
оружие и арены.

Пиксель-арт, сеттинг — угасающая межзвёздная теократия на пепле великой войны.

**Играть: https://ash.sanyago.space**

## Дисклеймер

Игра **не связана с Games Workshop** и не является продуктом или производной работой
по какой-либо их франшизе. Сеттинг, названия, персонажи, оружие и все ассеты —
оригинальные. Совпадения жанровых архетипов (готическая архитектура, силовая броня,
фанатичная теократия, техно-жрецы) относятся к общим жанровым тропам гримдарк-сай-фай.

## Как играется

- **Забег** — 20 волн, длина растёт с 20 до 60 секунд; волны 10 и 20 — боссы.
- **Бой автоматический**: до 6 слотов оружия, каждое со своим кулдауном, радиусом
  и приоритетом цели. Управление — движение и позиционирование.
- **Между волнами** — лавка: покупка оружия и предметов, апгрейд тиров, реролл,
  блокировка витрины. Плюс выбор одного из перков при уровне.
- **Валюта забега** — прах (падает с врагов, собирается автоматически в конце волны).
  **Валюта меты** — реликвии, начисляются сервером по своей формуле.
- **Кооп** — комната по коду, до 8 игроков, общий пул врагов и раздельные кошельки.

- **Мини-ивенты на арене** — ломаемые объекты: реликварий лечит, урна роняет прах,
  кадило расшвыривает толпу, тяговый камень стягивает её в кучу под залп. Встают
  заново каждую волну на точках, вычисленных из сида, — по сети не передаются.

Управление: `WASD` / стрелки — движение, `F3` — дебаг-оверлей (fps, мс sim/render,
трафик, пинг, роль, сид). **Геймпад** работает и в бою, и в меню: крестовина и
левый стик двигают фокус, `A` нажимает, `B` — назад, `Start` — пауза; в лавке
`X` блокирует слот, `Y` объединяет, `LB` — реролл. Раскладка — `config.input`.

Звук: музыка меняется по фазе и номеру волны, громкость музыки и эффектов правится
из главного меню и из паузы и переживает перезапуск. Все треки — CC0, авторы
перечислены и в игре, и в `CREDITS.md`.

## Контент

| | |
|---|---|
| Фракции | 7 |
| Персонажи | 14 |
| Оружие | 28 базовых × 4 тира (112 записей конфига) |
| Предметы | 64 |
| Враги | 18 обычных + 6 элитных |
| Боссы | 6 |
| Арены | 3 |
| Достижения | 10 |
| Языки интерфейса | ru, en |

Весь контент — данные в `config/game_config.json`. Код оперирует ключами: ни названий,
ни чисел баланса, ни texture-id в исходниках нет.

## Стек

- **Backend**: Flask + Flask-SocketIO (threading + simple-websocket), SQLite, Docker.
  Сервер **не считает игру** — только релей сообщений комнат, аккаунты, конфиг, мета
  и лидерборды. Зависимостей четыре: `flask`, `flask-socketio`, `simple-websocket`,
  `werkzeug`.
- **Frontend**: vanilla JS (ES-модули, без сборщика и npm), Canvas 2D, симуляция
  60 Hz в браузере.
- **Кооп**: host-authoritative — браузер хоста считает мир и рассылает снапшоты 20 Hz,
  остальные шлют ввод 60 Hz и предсказывают своё движение. Соло — это комната из одного игрока через
  `LocalTransport`, отдельной ветки кода для соло нет.

### Архитектура

```
Хост (браузер)                 Сервер (Flask + SocketIO)          Клиенты (браузеры)
 sim 60 Hz, весь мир    ──20Hz─►  релей комнат: emit(room=code)  ──►  ввод 60 Hz
 приём ввода 60 Hz      ◄───────  без симуляции                  ◄──  предсказание
 рассылка снапшотов               /api/*, SQLite, мета                рендер 60 Hz
```

Бюджет кадра при 8 игроках, 450 врагах и 600 снарядах: sim ≤ 6 мс, рендер ≤ 6 мс,
сеть ≤ 2 мс. Сущности — из пулов, коллизии — через uniform spatial hash, снапшоты —
дельта-кодированные int16/uint8 в радиусе видимости клиента.

## Запуск локально

```bash
docker compose up -d --build
# http://127.0.0.1:8150
```

Данные (аккаунты, живой конфиг, ключ сессий) — в volume `data/`, в репозиторий
не попадают. Живой конфиг создаётся из `config/game_config.json` при первом старте;
дальше правки контента накатываются идемпотентными скриптами `tools/patch_config_*.py`
в обе копии.

В проде — nginx + Let's Encrypt перед контейнером, порт 8150 слушает только localhost.

## Тесты

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # разово
.venv/bin/python -m pytest tests/py -q   # сервер: API, мета, реестр комнат, валидация забегов
node --test tests/js/*.test.js           # формулы sim: статы, XP, лавка, экономика
node tools/bench_sim.js                  # бюджет производительности симуляции
node tools/playtest.js --god             # автопрогон забега: кривая дохода по волнам
node tools/coop_income.js                # прах на игрока при 1/2/4/8 участниках
```

Сквозные проверки в настоящем браузере (нужен поднятый контейнер и playwright):

```bash
.venv/bin/python tools/smoke.py                                   # забег, fps, ошибки консоли
.venv/bin/python tools/pad_test.py                                # навигация по меню геймпадом
.venv/bin/python tools/coop_test.py --players 8 --latency 80      # 8 браузеров в одной комнате
```
