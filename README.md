# Прах и Железо

Браузерный арена-рогалик-автошутер: 20 волн на замкнутой арене, соло или в комнате
до 8 игроков. Оружие бьёт само — игрок бегает и принимает решения в лавке между
волнами. За забеги начисляются реликвии, за них открываются фракции, персонажи,
оружие и арены.

Пиксель-арт, сеттинг — угасающая межзвёздная теократия на пепле великой войны.

## Дисклеймер

Игра **не связана с Games Workshop** и не является продуктом или производной работой
по какой-либо их франшизе. Сеттинг, названия, персонажи, оружие и все ассеты —
оригинальные. Совпадения жанровых архетипов (готическая архитектура, силовая броня,
фанатичная теократия, техно-жрецы) относятся к общим жанровым тропам гримдарк-сай-фай.

## Стек

- **Backend**: Flask + Flask-SocketIO (threading + simple-websocket), SQLite, Docker.
  Сервер **не считает игру** — только релей сообщений комнат, аккаунты, конфиг, мета
  и лидерборды.
- **Frontend**: vanilla JS (ES-модули, без сборщика), Canvas 2D, симуляция 60 fps
  в браузере.
- **Кооп**: host-authoritative — браузер хоста считает мир, остальные шлют ввод и
  получают снапшоты. Соло — это комната из одного игрока через `LocalTransport`.

## Запуск локально

```bash
docker compose up -d --build
# http://127.0.0.1:8150
```

Данные (аккаунты, живой конфиг, ключ сессий) — в volume `data/`.

## Тесты

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt   # разово
.venv/bin/python -m pytest tests/py -q   # сервер: API, мета, валидация забегов
node --test tests/js/*.test.js       # формулы sim: статы, XP, лавка, экономика
node tools/bench_sim.js                  # бюджет производительности симуляции
```
